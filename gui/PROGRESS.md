# gui 진행 상황

electron 기반의 GUI DB툴을 개발하는 프로젝트이다. HelloWorldDB 용으로 먼저 만들고(15단계), MySQL, MariaDB, PostgreSQL 지원을 더한다(16단계).
사양은 루트의 AGENTS.md 가 기준이다. 이 문서에는 세부 계획, 진행 상황, 인수인계 사항만 적는다.
아래의 단계 번호(15-1 등)는 보류 전 계획에서 쓰던 번호이다. "상세 N" 은 AGENTS.md "RDBMS 에 구현되어야 할 사항 (상세)" 의 N번 절을 가리킨다.

## 세부 계획 초안 (보류 전의 15단계. HelloWorldDB 용 DB툴)

### 15-1. 기반

- [ ] electron 프로젝트 구성. 패키지명은 `org.duckdns.hjow.helloworlddb.gui` 이다 (AGENTS.md 지켜야 할 사항 6). 내장된 Node.js 가 22 이상인 electron 버전을 쓴다 (`nodejsDriver` 의 요구 사항)
- [ ] UI 프레임워크를 정하고 구성한다 (미결 사항)
- [ ] 프로세스 분리 : DB 접속은 메인 프로세스에서만 한다. 화면(렌더러)은 preload 로 노출한 IPC 로만 요청한다. `contextIsolation` 을 켜고 렌더러의 `nodeIntegration` 은 끈다
- [ ] 패키징 구성

### 15-2. DB 어댑터

- [ ] 어댑터 인터페이스 정의 : 접속과 종료, 문장 실행, 결과 나누어 받기, 트랜잭션 제어, 메타데이터 조회(객체 계층, 테이블, 컬럼, 인덱스, 뷰, 제약조건), DDL 문장 만들기, DB 마다 다른 기능의 지원 여부 알리기
- [ ] HelloWorldDB 어댑터 : `nodejsDriver` 로 구현한다. 메타데이터는 SYSTEM 의 딕셔너리 뷰에서 읽는다 (상세 3)
- [ ] 화면 코드는 어댑터 인터페이스만 쓴다. 특정 DB 에 묶인 코드를 화면에 두지 않는다

### 15-3. 화면 기능

- [ ] 접속 정보 관리 : 추가, 수정, 삭제, 접속 시험. HelloWorldDB 의 접속 대상은 호스트와 포트 번호만으로 정한다 (상세 15). 비밀번호는 평문으로 저장하지 않는다 (electron 의 `safeStorage` 사용)
- [ ] 객체 탐색 : 테이블스페이스, 테이블, 뷰, 인덱스, 사용자, 권한
- [ ] SQL 편집기 : 구문 강조, 선택한 부분 또는 커서가 있는 문장 실행, 여러 탭
- [ ] 결과 표 : 큰 결과는 스크롤에 따라 fetch 단위로 더 받아 온다. NULL 표시, 값 복사
- [ ] 테이블 데이터 편집 : PK 로 행을 특정하여 수정, 삭제, 추가한다. PK 가 없는 테이블은 읽기 전용으로 연다
- [ ] DDL 보기 : 테이블, 뷰, 인덱스
- [ ] 트랜잭션 : 자동 커밋 전환, 커밋, 롤백. 커밋하지 않은 변경이 있으면 화면에 표시한다
- [ ] 사용자와 권한 관리 : 사용자 생성과 변경, GRANT, REVOKE (상세 4, 5, 6)
- [ ] 오류 표시 : SQLSTATE 와 메시지
- 완료 기준 : DB툴만으로 테이블 생성부터 데이터 입력, 조회, 권한 부여까지 할 수 있다.

## 세부 계획 초안 (보류 전의 16단계. 타사 오픈소스 DB 지원)

- [ ] MySQL 어댑터(`mysql2`), MariaDB 어댑터(`mariadb`), PostgreSQL 어댑터(`pg`)
- [ ] DB 종류별 접속 정보 입력 화면
- [ ] 메타데이터 조회 : 각 DB 의 `information_schema` 등에서 읽는다
- [ ] 객체 계층의 차이 : HelloWorldDB 는 테이블스페이스, MySQL 과 MariaDB 는 데이터베이스, PostgreSQL 은 데이터베이스와 스키마
- [ ] SQL 방언의 차이 : 식별자 인용 부호, 행 수 제한 문법, 데이터 타입 이름
- [ ] DB 가 지원하지 않는 기능은 화면에서 숨기거나 쓸 수 없게 한다
- [ ] 세 DB 각각에 대한 통합 테스트. 시험용 DB 를 띄우는 방법을 마련한다
- 완료 기준 : 세 DB 각각에 접속하여 객체 탐색, SQL 실행, 데이터 편집이 된다.

## 인수인계 사항

- 16단계의 작업량은 15단계에서 어댑터 경계를 얼마나 지켰는지에 달려 있다. 화면 코드가 HelloWorldDB 의 딕셔너리 뷰 이름이나 문법을 직접 알게 하지 않는다.
- `nodejsDriver` 의 공개 API 가 바뀌면 HelloWorldDB 어댑터만 고치면 되어야 한다.
