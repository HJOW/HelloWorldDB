# 데이터 타입 인자와 기본값

AGENTS.md 개요 1과 상세 1-1, 13을 따른다. 현재 `src/types/dataType.ts`는 아래 기본값 상수와 고정소수 타입 인자 해석을 제공한다. 전체 타입 시스템, 값 연산 및 SQL 파서는 후속 작업이다.

| 타입 선언 | 적용하는 정의 |
|---|---|
| `VARCHAR`, `NVARCHAR` | 길이 65,535. 명시한 길이도 최대 65,535 |
| `DECIMAL`, `DEC`, `NUMERIC` | `DECIMAL(10,3)` |
| `DECIMAL(p)`, `DEC(p)`, `NUMERIC(p)` | `DECIMAL(p,0)` |
| `DECIMAL(p,s)`, `DEC(p,s)`, `NUMERIC(p,s)` | `DECIMAL(p,s)` |

문자 길이는 바이트가 아닌 유니코드 코드 포인트 단위이다. NVARCHAR는 VARCHAR와 동일하게 처리한다. 고정소수 정밀도는 1~38, 소수 자릿수는 0~정밀도이다. 최대 정밀도 38과 인자 전체 생략 시 기본 정밀도 10을 구분한다. 세 고정소수 타입은 `resolveExactNumericType()`에서 같은 DECIMAL 정의로 정규화한다. 잘못된 인자는 SQLSTATE `22023`, 내부 오류 번호 2000이다.

드라이버와 DB툴은 컬럼의 실제 길이/정밀도/소수 자릿수를 서버 메타데이터에서 읽어야 한다. 기본값 `(10,3)`은 인자를 모두 생략한 타입 선언에만 적용하며 조회된 값의 형식을 강제로 바꾸는 규칙이 아니다.

SQL 카탈로그를 저장할 때는 해석한 타입 인자를 명시적으로 기록한다. 저장 형식은 [storage-v1.md](storage-v1.md)의 버전 규칙을 따른다. 1.0 출시 전에는 포맷 번호를 유지한 변경과 기존 호환성 생략이 가능하며 문서와 테스트 자료를 함께 갱신한다.
